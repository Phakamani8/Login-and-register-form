# NUE NUE — Registration & Sign-In Form

A registration and sign-in interface built with HTML, CSS, and JavaScript.

## Features

* Registration form
* Sign-in form
* Switching between registration and sign-in forms
* Styled form inputs and buttons
* Background image and gradient overlay
* Font Awesome integration
* Hover effects

## Built With

* HTML5
* CSS3
* JavaScript
* Font Awesome

## Purpose

This project demonstrates a simple front-end form interface with JavaScript used to switch between the registration and sign-in forms.
