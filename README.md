# NUE NUE – Login and Registration System

## About the Project

NUE NUE is a web-based authentication system that allows users to create accounts and securely sign in using their registered credentials.

The project demonstrates frontend development, backend processing, and database integration.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Form interactions and client-side functionality
- PHP – Backend processing and authentication
- MySQL – User data storage

## Features

- User registration
- User login
- Email and password validation
- Secure password hashing
- Database integration
- Session-based authentication
- Login feedback and error messages

## How It Works

1. Users create an account through the registration form.
2. Their details are processed by PHP.
3. User information is stored in a MySQL database.
4. Passwords are hashed before storage.
5. Registered users can sign in using their email and password.
6. PHP verifies their credentials and creates an authenticated session.

## Installation

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Place the project folder inside XAMPP's `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Create a MySQL database named `nuenue`.
6. Configure the database connection in `db.php`.
7. Open the project in your browser:

   `http://localhost/Nue-Nue/`
